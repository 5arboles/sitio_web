# Thermair - Sitio Web Corporativo

Sitio web corporativo y de ingeniería para **Thermair | Climatización & Distribución Eléctrica**.

## 🚀 Despliegue en Producción
- **Vercel**: [https://sitioweb-orcin.vercel.app](https://sitioweb-orcin.vercel.app)

## 📁 Estructura del Sitio
- `index.html`: Hero scrollytelling con despiece 3D de split YORK Inverter (100% de pantalla con HUD superior e inferior), KPIs corporativos y formulario de contacto.
- `alianzas.html`: Alianzas Profesionales para proyectistas, arquitectos y constructoras (BIM, CAD, balance térmico).
- `electricidad.html`: Infraestructura Eléctrica Corporativa (Media y Baja Tensión, tableros TGBT).
- `climatizacion.html`: Climatización Integral y estimador interactivo de capacidad.
- `mantenimiento.html`: Mantenimiento predictivo, preventivo y guardia técnica 24/7.
- `assets/`: Recursos gráficos oficiales y video optimizado para scrollytelling (`york-scrub.mp4`).
- `css/`: Estilos personalizados y controladores de scrubbing.
- `js/`: Scripts complementarios.
